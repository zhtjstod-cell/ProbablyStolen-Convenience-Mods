[**편의성 모드 모음집 / Quality-of-life mods on Steam Workshop**](https://steamcommunity.com/sharedfiles/filedetails/?id=3831804781)

편의성 모드는 Steam 창작마당에서 구독하세요. 이 저장소에서는 한글패치만 배포합니다.

## 한글패치 설치

1. 게임을 완전히 종료합니다.
2. 위 한글패치 다운로드에서 `ProbablyStolen-Korean-Mod-v1.0.9.zip`을 받습니다.
3. 압축 안의 `Mods` 폴더를 `Probably Stolen.exe`가 있는 폴더에 합칩니다.
4. 게임의 **Mods** 메뉴에서 **Probably Stolen 한국어**를 활성화합니다.
5. 게임을 완전히 종료한 뒤 다시 실행하고 언어 목록에서 **한국어**를 선택합니다.

최종 경로는 `Mods/ProbablyStolenKorean/manifest.xml`입니다. 별도 모드 로더를 설치할 필요가 없습니다.

For quality-of-life mods, subscribe through the Steam Workshop collection linked above. This repository distributes only the Korean language patch.
